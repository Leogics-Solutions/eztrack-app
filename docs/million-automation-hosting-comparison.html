Million Automation Hosting Options

Decision paper: dedicated on-premise PC vs. Windows cloud VM connected through a private VPN

Recommendation: choose a dedicated on-premise automation PC for the first production rollout. It keeps Million close to its local SQL database, has fewer network failure points, and becomes cheaper than the cloud route after roughly 8–11 months. Choose the cloud VM only when remote operations and off-site resilience justify the recurring cost and a successful latency pilot.
Option 1 · preferred for V1

Dedicated automation PC

  • Lowest latency to Million and its database.
  • Works even if the internet is temporarily unavailable for local processing.
  • Requires office power, local hardware care and a UPS.
Option 2 · cloud + private VPN

Windows cloud VM

  • Off-site operation and simpler remote support.
  • Needs stable office internet, VPN monitoring and a latency pilot.
  • Internet/VPN failure stops Million access to the local database.

How the private VPN option should be implemented

Secure design

  • Install a VPN connector at the office network edge. It initiates the connection outbound; do not expose the Million SQL port to the internet.
  • Cloud VM receives jobs from Smartdok over HTTPS and talks to Million only across the encrypted private tunnel.
  • Allow the cloud VM to reach only the required Million server IP and port; deny lateral network access.
  • Use MFA, named administrator accounts and IP-restricted remote support. No internet-facing RDP.
  • Encrypt VM disks, take daily backups, and retain automation logs/screenshots outside the VM.

Cloud pilot acceptance tests

  • Million opens and saves a demo Purchase Invoice and Sales Invoice reliably over the tunnel.
  • At least 50 consecutive rehearsal jobs complete with no duplicate document numbers.
  • VPN reconnect recovers cleanly after office internet outage and VM restart.
  • Automation detects a partially entered form and stops for review rather than retrying blindly.
  • Million licensing, USB-dongle availability and vendor support are confirmed for the VM.
